I've added a new section to the homepage - [Vibelets!](https://codemade.net/#vibelets) 

These are tiny applications that I had an LLM (Usually Claude) build for very specific tasks. The main idea is that they are small, single-task web apps that run entirely in the browser, and that I can trust to not send my data anywhere.

The classic example is the [JSON to YML](https://codemade.net/vibelets/json-to-yaml/) converter. I don't want to send sensitive json configuration out to some random website, I don't want my data to be stored in a database, or logged, or even worse, sold to advertisers and scammers.

Of course, the irony is that I am now hosting these apps here and asking you to trust me!

But at least this website is [completely open source](https://github.com/LBognanni/codemade-site), and you can verify that it doesn't in fact have any nasty surprises ☺️
